Политика конфиденциальности

2. Какие данные могут обрабатываться

  • имя или псевдоним, если пользователь указал его добровольно;
  • город, если пользователь указал его добровольно;
  • текст пользовательской записи;
  • технические данные, необходимые для работы сайта и защиты управления записью;
  • информация о факте и статусе платежа, идентификаторе платежа и сумме.

3. Цели обработки

  • создание и публикация записи;
  • предоставление пользователю возможности управлять записью;
  • подтверждение оплаты и исполнение оплаченной услуги;
  • обеспечение безопасности и работоспособности сервиса;
  • обработка обращений пользователей.

4. Платёжные данные

Оплата проводится на защищённой платёжной странице Т-Банка. Сайт не получает и не хранит полный номер банковской карты, срок действия и CVC/CVV. Обработка платёжных реквизитов осуществляется платёжной инфраструктурой Т-Банка.

5. Техническая инфраструктура

Для работы сервиса используется сторонняя инфраструктура, включая GitHub Pages для размещения интерфейса сайта и Supabase для хранения данных и серверной логики. В рамках работы этих сервисов могут обрабатываться технические данные, необходимые для предоставления услуги.

6. Локальное хранение в браузере

Сайт может сохранять в браузере пользователя технический секретный ключ, необходимый для управления созданными записями. Пользователь может потерять доступ к управлению записью при очистке данных браузера, если отдельно не сохранил секретную ссылку.

7. Публичность записи

Пользователь понимает, что оплаченная опубликованная запись, а также указанное в ней имя/псевдоним и город становятся общедоступными в сети Интернет.

8. Срок обработки и удаление

Информация хранится в течение периода, необходимого для функционирования сервиса, исполнения обязательств и соблюдения требований законодательства. По вопросам обработки или удаления данных пользователь может обратиться по указанному контактному email.

9. Изменения политики

Политика может обновляться при изменении работы сервиса или требований законодательства. Актуальная версия размещается на этой странице.
