# Виртуальный ЗАГС — тестовая интеграция

Ветка: `zags-integration`. Рабочая `main` не меняется.

## Реализовано
- /zags/index.html — интерфейс и демонстрация.
- Подключение Supabase из `../config.js` (публичный ключ).
- Email OTP через `signInWithOtp` и `verifyOtp`.
- Вход перед приватными операциями и перед проверкой приглашения.
- Серверные вызовы `zags_action` для работы с парами.
- `paymentsEnabled:false`: UI не инициирует оплату.

## Не считать запуском в эксплуатацию
- Файл находится только в отдельной ветке; GitHub Pages публикует рабочую ветку.
- Реальные платежи отключены и не должны включаться до отдельных тестов.
- Публичные страницы сейчас требуют входа, потому что у роли `anon` нет EXECUTE для `zags_action`.
- Необходимо провести ручной тест с ДВУМЯ независимыми email-аккаунтами, регистрации пары, приглашения, принятия и чтения.
- Необходимо проверить SQL-валидаторы входных данных и лимиты длины, RLS и права SECURITY DEFINER на продакшен-базе.
- Проверить фактическое действие OTP и подтвердить, что письмо приходит с 6-значным кодом.
- Не передавать клиентскому коду service-role ключи, токены платежей или SMTP-пароли.
