# Перенос виртуального ЗАГСа на существующий Beget — инженерная подготовка

**21.10.2026. Черновик. Никаких изменений на VPS/локальном Supabase не выполнено.** Документ предназначен для подготовки, не является утверждением, что локальная инфраструктура полностью соответствует требованиям обработки персональных данных.

## Подтверждено совместными проверками

- Beget Cloud VPS «Ingenious Roman», Санкт-Петербург, Ubuntu, публичный IP указан в панели Beget (не публикуется в инструкции); **2 CPU / 4 ГБ RAM / 40 ГБ NVMe**.
- Домен `api.smoke-tattoo.ru` разрешается на этот VPS. На VPS работают Docker и самостоятельно развёрнутый Supabase, включая `supabase-db`, `supabase-auth`, `supabase-storage`, `supabase-edge-functions`, `supabase-caddy`.
- В локальном PostgreSQL `postgres` обнаружены **14 таблиц `tp_*`** TATTOO PRICE. Наличие таблиц подтверждает локальное хранение части данных, но не гарантирует, что **все** API и данные приложения обслуживаются только VPS: возможны внешние компоненты.
- Доступно около **8 ГБ диска**, использование ~79%; `docker system df` показывает заметные объёмы reclaimable, но очистка Docker до анализа назначения образов запрещена.
- PostgreSQL принимает соединения: `pg_isready` вернул `accepting connections`.
- Создан PostgreSQL `pg_dump` базы `postgres` в custom format на VPS, список объектов успешно читается `pg_restore -l`; копия **510081 байт** скачана на Windows ПК как `tattoo-price-2026-10-21.dump` в пользовательской папке Windows. Вычисление локального SHA256 выполнено. Сравнение контрольной суммы с серверной копией **ещё не выполнено**.
- На Beget найден старый снимок `TATTOO-PRICE-before-migration` от 14.09.2026; автоматические копии в панели Beget не обнаружены. Старый снимок не заменяет свежий проверенный полный бэкап.
- `pg_dump` охватывает базу PostgreSQL, **но не обязательно охватывает Docker volumes, само содержимое пользовательских файлов Supabase Storage, конфигурацию Caddy, Edge Functions, .env и внешние сервисы**.
- Проект «Я был здесь» и существующий ЗАГС пока используют другой облачный Supabase `qgccfpkvzrimwqmqrxwq` (`eu-west-1`); TATTOO PRICE в существующем репозитории использует `https://api.smoke-tattoo.ru`.
- ЗАГС в EU содержит одну неоплаченную пару с принятым приглашением; нельзя копировать этот набор без рассмотрения пользователей, идентификаторов, согласий и безопасной повторной авторизации.
- Боевые платежи ЗАГСа выключены, DEMO-маршрут закрыт. Веб-сайт со свидетельством, фронтенд и основной эквайринг продолжают работать независимо.

## Целевая архитектура

Предпочтительный вариант — **поместить таблицы нового ЗАГСа в отдельную схему `zags` существующего локального PostgreSQL** вместо дорогостоящего повторного поднятия полного набора Docker-контейнеров Supabase. Публичные RPC и авторизация должны иметь независимые права, ограниченные только данными ЗАГСа. Все `tp_*` таблицы, триггеры, функции и существующие Docker Compose настройки TATTOO PRICE должны оставаться без изменений.

Это ещё не готовая миграция: существующие функции `public.zags_action` и `public.zags_payment` из EU-сервиса сейчас ссылаются на **`public.zags_couples` / `public.zags_wishes`**. Их нельзя переносить дословно и просто надеяться, что они будут работать в схеме `zags`. Прежде чем включать UI и платежи, требуются адаптированные функции, правильные SQL grants/RLS, API-доступ, изоляция пользователей, проверка OAuth/OTP и банковских webhook.

Чтобы не модифицировать чужие приложения, первый запуск должен быть **отдельной технической средой / API с синтетическими учётными записями**, не публичной ссылкой для покупателей.

## Порядок работ

1. **Завершить защиту существующего TATTOO PRICE.** Сравнить SHA256 локального и серверного файлов, проверить содержимое и хранить обе копии; отдельно скопировать Storage uploads и конфигурацию контейнеров/маршрутизации в защищённое внешнее хранилище. До этого не трогать действующий PostgreSQL.
2. **Read-only аудит VPS:** список активных Caddy маршрутов **без секретов**, распределение Docker volumes по размеру, список таблиц и ролей Postgres без содержимого; проверить свободное место. Не отправлять в чат содержимое конфигурации с ключами.
3. **Изолированная схема ЗАГСа:** подготовить `zags.couples`, `zags.wishes` с ограничениями и RLS, отдельные функции и права. Данные TATTOO PRICE не изменять. SQL из Cloud необходимо адаптировать и пройти ревью.
4. **Auth:** определить использование уже существующего локального `supabase-auth` с отдельными учётными записями. Cloud Auth UUID/JWT, письма и OTP не переносить слепым копированием или передачей секретов в чате.
5. **Технический API:** отдельный тестовый hostname/path, HTTPS, строгий CORS, rate limit, системный журнал без персональных данных и секретов. В существующие `api.smoke-tattoo.ru` платежные маршруты не вносить изменений, пока не проверена изоляция.
6. **Церемония:** автоматические тесты двух участников, одноразовых приглашений, отказа от публичной публикации, запрета доступа к чужим данным, нет оплаченного свидетельства до факта банка.
7. **Оплата и чеки:** адаптировать отдельный `zags-payment` для нового API, корректной службы подписей, `GetState`, Webhook и банковского чека. Тарифы строго из БД (149/299/499 ₽). Боевые платежи включать только после полноценной приёмки.
8. **Приватность и миграция:** выбрать законный способ переноса существующей одной заявки и доступов; разместить актуальные условия и политику. Старую систему оставить для отката до завершения проверки.
9. **Резервирование:** ежедневные копии базы плюс файлов, отдельное хранилище, проверяемое восстановление в изолированную тестовую среду. Только после этого открывать доступ покупателям.

## Команда для будущей безопасной проверки

`zags/beget/readonly-preflight.sql` — **только SELECT**, выводит наличие локального Auth, имена роли и количество таблиц, не читает личные данные, не меняет сервисы. Запускать при следующем совместном техническом сеансе, а не вместо резервного копирования.

## Не делать

- `docker system prune -a`, `docker volume prune`, удаление снапшота от 14.09, пересоздание Supabase, замену `.env`, откат бэкапа поверх работающего сервера.
- Публикацию приватных SQL-дампов, токенов, CVV, паролей и ключей в GitHub или в чате.
- Переключение `api.smoke-tattoo.ru` на новый backend, изменение функций TATTOO PRICE и основного «Я был здесь».
- Миграцию персональных данных и приём реальных платежей без завершения проверок.
