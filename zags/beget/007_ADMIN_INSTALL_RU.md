# Админка Beget для ЗАГСа

`zags/admin.html` подключается к локальному Beget API. Панель показывает сводку и список заявок; секрет приглашения, клятвы, фото и идентификаторы пользователей в интерфейс не возвращаются. Изменять или удалять заявки из панели нельзя.

## Установка

1. Убедиться, что на Beget уже установлены `zags.couples`, `zags.wishes` и `zags.preview_testers`.
2. Запустить установщик в SSH от root. Он сам проверит состояние, создаст и проверит резервную копию, скачает SQL по фиксированному commit SHA, применит миграцию и проверит права. Если проверка не проходит, установщик остановится без изменений:

```bash
set -o pipefail; curl -fsSL 'https://raw.githubusercontent.com/dimontattoo495-afk/ya-byl-zdes/566fb77cdf988fd80ecd60cd2236583f5b332f82/zags/beget/install-admin-panel.sh' | bash -s -- 566fb77cdf988fd80ecd60cd2236583f5b332f82
```

Миграция создаёт ноль администраторов. Установщик не меняет пользователей, Auth, почту, платежи или таблицы TATTOO PRICE.
4. Создать/подтвердить отдельный аккаунт администратора на Beget. Не отключать подтверждение email для всей общей Auth.
5. Выдать право только точному подтверждённому аккаунту, заменив адрес в запросе ниже на адрес администратора. Выполнять только на Beget:

```sql
INSERT INTO zags.admins (user_id)
SELECT id
FROM auth.users
WHERE lower(email) = lower('ADMIN_EMAIL_HERE')
  AND email_confirmed_at IS NOT NULL
ON CONFLICT (user_id) DO NOTHING;
```

Проверить, что добавлена ровно одна строка:

```sql
SELECT count(*) = 1 AS admin_added
FROM zags.admins AS a
JOIN auth.users AS u ON u.id = a.user_id
WHERE lower(u.email) = lower('ADMIN_EMAIL_HERE');
```

6. Опубликовать страницу на `https://yabylzdes.ru/zags/admin.html` и проверить HTTPS, CORS и авторизацию.
7. Войти аккаунтом администратора. Остальные подтверждённые аккаунты, включая TATTOO PRICE, должны получить отказ.

Не помещать пароль, JWT или `service_role` ключ в GitHub, браузерный код, чат или скриншоты. В браузере используется только уже опубликованный публичный anon key.

## Текущая граница

Раздел ЗАГСа использует Beget. Кнопка «Я был здесь» открывает существующую панель `/admin.html`, чья база и авторизация пока остаются отдельными. Эта версия объединяет точку входа и навигацию, но не переносит базу или данные «Я был здесь» и не делает их общим аккаунтом.
