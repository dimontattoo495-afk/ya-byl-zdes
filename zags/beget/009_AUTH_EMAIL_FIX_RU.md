# Почта и возврат из авторизации ЗАГС

## Что подготовлено

Форма ЗАГСа запрашивает одноразовый код, передаёт Auth адрес возврата на страницу ЗАГСа и указывает отдельное название приложения. Русские шаблоны подтверждения и входа уже добавлены в сайт. В них есть код и кнопка, а бренда Tattoo Price нет.

## Установка на Beget

Auth общий с Tattoo Price. Скрипт ниже сохраняет существующий список redirect URL и добавляет только ЗАГС. Он не меняет базовый `SITE_URL`, SMTP-настройки, пароли или базы. Перед запуском он проверяет, что оба письма уже доступны с сайта; создаёт резервные копии `.env` и `docker-compose.yml`; добавляет недостающие переменные шаблона входа; проверяет Compose; перезапускает только Auth и проверяет его здоровье. Если проверка не проходит, он возвращает старые файлы и конфигурацию Auth.

Из уже открытого root SSH shell выполните одну команду:

```bash
curl -fsSL -o /tmp/zags-auth-email-fix.sh https://raw.githubusercontent.com/dimontattoo495-afk/ya-byl-zdes/main/zags/beget/fix-auth-email.sh && bash /tmp/zags-auth-email-fix.sh
```

Скрипт завершится без изменений, если письма ещё не опубликованы или конфигурация отличается от ожидаемой. Не присылайте пароль, содержимое `.env` или ключи в чат.

## Проверка

После сообщения `PASS` проверьте регистрацию на отдельной тестовой почте: письмо должно быть на русском с кодом, а переход по кнопке должен открывать ЗАГС. Затем проверьте, что письмо и переход при входе в Tattoo Price работают как раньше. Персональное имя из user metadata используется только как название приложения в письме — оно не влияет на авторизацию или доступ к данным.
