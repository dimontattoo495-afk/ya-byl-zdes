# Почта и возврат из авторизации ЗАГС

## Что исправлено в коде

ЗАГС передаёт Auth адрес возврата текущей страницы и название приложения для персонализации письма. Для регистрации и повторного входа подготовлены отдельные русские шаблоны. В них есть одноразовый код и запасная кнопка подтверждения/входа; шаблоны не показывают название TATTOO PRICE.

## Что нужно включить на общем Beget Auth

Это один общий Auth для нескольких сайтов, поэтому не меняйте его базовый `GOTRUE_SITE_URL` без отдельной проверки Tattoo Price. Сохраните все уже разрешённые адреса и **добавьте** точный адрес ЗАГСа:

```text
https://yabylzdes.ru/zags/**
```

Не заменяйте список целиком и не используйте широкий шаблон для всех доменов. Адрес в ссылке письма берётся из `emailRedirectTo`; если Auth не считает его разрешённым, может подставить общий адрес сайта.

Настройте шаблоны Auth:

```text
GOTRUE_MAILER_TEMPLATES_CONFIRMATION=https://yabylzdes.ru/zags/email-templates/confirmation.html
GOTRUE_MAILER_SUBJECTS_CONFIRMATION=Подтвердите почту
GOTRUE_MAILER_TEMPLATES_MAGIC_LINK=https://yabylzdes.ru/zags/email-templates/magic-link.html
GOTRUE_MAILER_SUBJECTS_MAGIC_LINK=Код для входа
```

Оставьте текущие SMTP параметры и `GOTRUE_MAILER_AUTOCONFIRM=false`. Auth должен получать эти шаблоны по HTTPS. После изменения переменных контейнер Auth нужно пересоздать/перезапустить способом, который перечитывает его environment.

## Проверка

1. Откройте ЗАГС и зарегистрируйте отдельный тестовый email.
2. Убедитесь, что письмо подписано именем приложения ЗАГСа и в нём есть числовой код.
3. Введите код в поле на странице регистрации; подтверждение должно остаться на `yabylzdes.ru/zags/`.
4. Проверьте, что вход уже созданного пользователя присылает код из шаблона `magic-link.html`.
5. Проверьте тестовую регистрацию Tattoo Price: разрешённый возврат и вход по существующей ссылке должны сохраниться.

Персонализированное имя берётся из `auth.users.user_metadata.auth_app_name`; для старых клиентов без этого поля будет показано нейтральное имя Admin. Метаданные используются только для текста письма, не для авторизации или доступа к данным.
