# Перевод тестового ЗАГСа на Beget

Этот комплект переводит API ЗАГСа на российский Beget Supabase. Общий `config.js`, API и платежи TATTOO PRICE остаются отдельными. Боевой checkout на сайте включается отдельным обновлением фронтенда.

## Что устанавливается

- Полный набор действий ЗАГСа в уже существующую изолированную схему `zags`.
- Функции раздельного согласия для новостей и публичная лента с двумя согласиями.
- Отдельный серверный endpoint `zags-payment`; он не может быть вызван ролью `anon` или `authenticated` и не создаёт платёж без `ZAGS_PAYMENTS_ENABLED=true` и заданных чековых параметров.
- Фронтенд ЗАГСа и новостная лента главной страницы используют Beget API `https://api.smoke-tattoo.ru`.

Пароль, JWT, `service_role` и банковские ключи в исходниках не хранятся. Установщик не вводит банковские секреты и не включает флаг оплаты.

## Установка на Beget

Установщик проверяет текущие таблицы, Auth, функцию `zags_v2_action`, Docker-сервис Supabase и 14 таблиц TATTOO PRICE. При неожиданном состоянии он останавливается до изменений. Затем он создаёт и проверяет свежую резервную копию, накатывает SQL в транзакции, устанавливает отдельную Edge Function и перезапускает только сервис функций.

Из root SSH shell выполните одну команду из инструкции к pull request, подставляя SHA, который указан в этой инструкции. Не вводите сюда пароли или секретные ключи. После успешного результата сайт можно переключить объединением подготовленного pull request. До этого момента текущая опубликованная версия остаётся без изменений.

Путь к резервной копии выводится установщиком в конце.

## Проверка после установки

Установщик проверяет гранты, включая отсутствие доступа `anon` и `authenticated` к платёжной RPC, наличие публичной ленты, сохранность 14 таблиц TATTOO PRICE и успешный перезапуск Edge Functions. Он не переключает сайт, не удаляет пользователей и не изменяет данные существующих заявлений.

Перед публичным запуском нужно отдельно проверить подтверждение email через Beget на двух аккаунтах, список redirect URL/CORS и работу писем. Данные аккаунтов и заявок, созданные до переключения в европейском проекте Supabase, в Beget автоматически не переносятся и должны быть отдельно удалены или перенесены до публичного запуска.

## Реальные платежи

Платёжный endpoint ЗАГСа использует отдельные переменные окружения `ZAGS_*` и проверку `ZAGS_PAYMENTS_ENABLED`. Публичный сайт и checkout нужно включать только после проверки боевого терминала и фактического формирования электронного чека. Тарифы и платежи TATTOO PRICE остаются отдельными.
